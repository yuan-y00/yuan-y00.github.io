# Yuan Portfolio

这是 Yuan / 李雯媛的个人作品集网站，发布目标为 GitHub Pages：

https://yuan-y00.github.io/

## 目录说明

- `index.html`：首页。
- `styles.css`：全站样式。
- `script.js`：主题切换、项目筛选、图片预览。
- `projects/`：两个公开项目详情页。
- `assets/`：网页实际引用的图片，已尽量使用脱敏或聚合版本。
- `content/projects/`：可公开长原文的存放位置。
- `source_assets/`：临时素材区，默认不需要公开放敏感材料。
- `tools/process_assets.py`：把本地可展示图片整理成网页图片的脚本。

## 长原文应该放在哪里

建议分三层存放：

1. **公开网页**：只放精简后的项目叙述、方法、工具、聚合指标和脱敏图。
2. **`content/projects/`**：放可公开的长原文版本，作为网页内容来源。
3. **本地硬盘、私有网盘或私有 GitHub 仓库**：放完整原始材料，包括客户姓名、邮箱、电话、合同、报价单、订单截图、原始访谈记录、内部复盘和成本数据。

不要把以下内容直接发布到 GitHub Pages：

- 用户邮箱、电话、姓名、WhatsApp 号码、Facebook 账号。
- 客户名称、合同、报价单、发票、订单截图和回款明细。
- 原始问卷逐条回答、完整访谈记录、内部会议纪要。
- 投放账户、Mailchimp 后台、域名绑定、支付系统信息。
- 未公开产品细节、供应商信息、内部成本和售后个案。

## 更新网站内容

1. 修改 `index.html` 或 `projects/<项目名>/index.html`。
2. 如果只是补长原文，把公开版 Markdown 放进 `content/projects/`。
3. 如果新增图片，把图片放进 `assets/` 下对应项目目录。
4. 本地检查无误后提交并推送到 GitHub。
