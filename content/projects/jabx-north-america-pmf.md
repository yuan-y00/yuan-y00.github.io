# JabX 北美 PMF 验证与后 PMF 用户运营

## 一句话简介

从 Kickstarter / CES 目标倒推北美高客单智能健身硬件的产品定义、人群、价格和用户资产路径。

## 项目时间

2026.04 - 2026.07

## 角色

海外市场 / PMF 研究 / 用户运营 / 项目执行与分析

## 工具与方法

- Kickstarter 众筹目标倒推
- CES 前置市场验证
- 北美市场调研
- 竞品对标
- Meta 广告测试
- 问卷和用户访谈
- Mailchimp 用户分层
- WhatsApp 社群运营
- Facebook 私聊触达
- 价格接受度分析
- 漏斗诊断
- 品牌征名共创

## 关键成果

- PD01 收回 126 份问卷。
- PD02 收回 333 份问卷。
- PD02 中 263 人表示愿意接受访谈。
- Mailchimp 原始记录 1,603 行，去重后 1,153 个邮箱用户。
- WhatsApp 运营 3 个用户群，共 98 名早期用户。
- PD01 Robot 广告 CTR 5.46%，CPL $2.67。
- 直接向 218 名愿意访谈用户发预约邮件后，实际到会只有 1 人，因此调整为“先激活、再私聊、再邀约”。

## 项目判断

拳击互动可以成为种子用户入口，但如果要支撑高客单价和更高众筹目标，JabX 不能只被定义成拳击器材，而要升级表达成一套家庭互动有氧训练系统。
